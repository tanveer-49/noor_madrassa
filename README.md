##  Features

###  **Qur'an Module**
- Read Qur'an with Arabic text
- Translation and transliteration
- Verse bookmarking
- Audio playback (coming soon)
- Adjustable font size

###  **Hadith Module**
- Authentic Hadith collections
- Sahih Bukhari, Sahih Muslim, and more
- Hadith bookmarking
- Grade and reference information

###  **Madrassa Courses** *(Coming Soon)*
- Structured Islamic courses
- Lesson tracking
- Progress monitoring
- Quiz assessments

###  **Islamic Library** *(Coming Soon)*
- Islamic books collection
- Bookmark and continue reading
- Categories: Aqeedah, Fiqh, Seerah, Tafsir

###  **Additional Features**
- Dark / Light mode
- Responsive design for all devices
- Bookmark saved content
- Search functionality

##  **Getting Started**

### Prerequisites

- Flutter SDK (>=3.0.0)
- Android Studio / VS Code
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/tanveer-49/noor_madrassa.git

# Navigate to project
cd noor_madrassa

# Install dependencies
flutter pub get

# Run the app
flutter run
